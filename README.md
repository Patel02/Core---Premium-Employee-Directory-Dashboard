# 🏢 Core - Premium Employee Directory Dashboard

Maine is assignment ko sirf ek technical task ki tarah nahi, balki ek **Real-world Product** ki tarah build kiya hai. Mera main focus tha ek aisa interface taiyar karna jo visually stunning ho aur use karne mein ek "Premium Experience" de.



## 🚀 Live Experience
**Live Demo:** [https://core-premium-employee-directory-das.vercel.app/](https://core-premium-employee-directory-das.vercel.app/)  
**Submission Deadline:** Feb 27, 2026

## ✨ Why this project stands out?

* **Pixel-Perfect Precision:** Maine Figma specs ko 100% follow kiya hai. Isme cards ka **24px radius**, Sidebar ka exact **#3D3936** background, aur Topbar ki **80px height** ko bariki se implement kiya hai.
* **Human-Centric UX:** Sirf design hi nahi, maine smooth transitions aur hover effects par bhi kaam kiya hai taaki user ko system ke saath interact karte waqt ek "Fluid" feel aaye.
* **Adaptive Design:** Sidebar mobile par ek smart overlay ban jata hai aur desktop par ek solid navigation unit, jo har device par perfect dikhta hai.
* **Enhanced Detail View:** Maine employee detail page ko kafi modern banaya hai jahan personal info aur biography ek structured card layout mein dikhti hai.

## 🛠️ Tech Stack & Tools

* **Framework:** React.js (Vite for lightning-fast bundling)
* **Styling:** Tailwind CSS (Customized with Figma Design System)
* **Routing:** React Router DOM v6
* **Icons:** Lucide React

## 📂 Project Architecture

Maine code ko "Clean Code" principles ke hisaab se organize kiya hai:
* `src/components`: Reusable UI elements jaise Topbar, Sidebar aur EmployeeCard.
* `src/pages`: Main view logic jisme EmployeeGrid aur detailed EmployeeDetail shamil hain.
* `src/employees.js`: Ek centralized mock database jo pure app mein data consistency maintain karta hai.

## ⚙️ How to run locally?

## 🧠 My Design Philosophy
Is project ko banate waqt maine kuch important decisions liye:
* **Modular Thinking:** Maine components ko aise divide kiya hai ki unhe future mein kisi bhi scaleable app mein asani se reuse kiya ja sake.
* **Attention to Detail:** Profile images par status indicators aur notification dots ko exact Figma position par rakha hai.
* **Performance:** Vite ka use karke maine ensure kiya hai ki assets load hone mein bilkul bhi deri na ho.
